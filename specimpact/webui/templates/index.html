Evidence, not vibes. 候補、relation path、引用を残す local-first 影響分析。

LOCAL-FIRST GRAPH IMPACT ENGINE

設計変更の爆風半径を、証拠つきで追跡する。

SpecImpact は設計書をローカル knowledge graph に変換し、変更要求から review candidate、relation path、引用行をまとめて出します。LLM は任意の副操縦士。判断は人間、根拠は保存。

サンプルで試す 影響分析へ
127.0.0.1 only JSONL state evidence-backed Codex CLI ready 
$ specimpact ingest docs --aliases aliases.yml
 graph: artifacts, entities, relations, evidence
$ specimpact analyze changes/change.md
 candidates: must / should / may
 proof: relation paths + quotes
$ specimpact why "カード入会申込API"
 because evidence beats guesswork
