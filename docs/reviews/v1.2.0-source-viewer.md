# v1.2.0 Source Viewer UX Review

## Implementation summary

- Replaced the flat Source Library with a searchable two-pane document browser.
- Opened the selected design document inline without a page transition.
- Added document-level search for Markdown/text rows, Excel cell values, and evidence fallbacks.
- Added Dirty Excel sheet selection, cell counts, and preserved evidence highlighting.
- Persisted the selected source in the `source` URL query and added a stacked mobile layout.
- Increased undersized labels and table text across the review workspace.

## Known limitations

- Excel is shown as an evidence-oriented cell table rather than reproducing the workbook canvas.
- Embedded images, shapes, charts, and drawing objects are not rendered in the viewer.
- The viewer is read-only; SpecImpact does not modify the original design document.
