# v1.3.0 Agent Host Phase 7 Review

## Implementation summary

The final acceptance phase hardened Dirty Excel sheet and region classification against embedded
revision history, added an external-interface benchmark workbook, and fixed the real Agent Host
flow with an end-to-end test. A natural-language credit-limit upper-bound change now retrieves
Screen, ValidationRule, API, DB Column, ExternalIF, and TestCase candidates with Evidence and graph
paths, submits host hypotheses through the verifier, persists a human decision, and projects that
decision to Obsidian.

## Changed files summary

- `specimpact/dirty_excel/sheet_classifier.py`: explicit SIer table-header signatures before
  fallback keyword scoring.
- `specimpact/dirty_excel/region_detector.py`: validation-first and table-specific region typing.
- `examples/dirty_sier_excel/docs/06_external_if_definition.xlsx`: external IF mapping sample.
- `tests/test_dirty_excel_v2.py`: real workbook classification regression coverage.
- `tests/test_agent_host_e2e.py`: full ingest, HostWorkflow, decision, and Obsidian acceptance path.
- `README.md`, `CHANGELOG.md`, and the benchmark guide: final measured scope and quality status.

## Test results

- `pytest -q`: 206 passed, 1 skipped in 27.02 seconds.
- `specimpact release-check ./examples/evaluation/release_cases.yml`: 21 cases passed.
- Real MCP stdio smoke: 17 typed tools, 4 workflow prompts, and resource discovery succeeded.
- Frontend `npm ci`, `npm run check`, and `npm run build`: passed.
- Python wheel `specimpact-1.3.0-py3-none-any.whl`: built and inspected.

The skipped test is the Windows symlink-escape case when the current account cannot create a
symbolic link. The boundary is covered on systems where that OS capability is available.

## Lint and compile results

- `ruff check .`: passed.
- `python -m compileall -q specimpact`: passed.
- `git diff --check`: passed; Git only reports expected Windows line-ending notices.

## Known limitations

- Image-only ER diagrams and semantic extraction from arbitrary Excel drawings remain unsupported;
  their presence is recorded as an unparsed warning.
- Cursor Canvas and Antigravity Artifacts are host projections. Local JSONL remains authoritative.
- SharePoint API, NotebookLM Enterprise, M365 Copilot remote MCP, and a VS Code Custom Editor are
  deferred to a later release.
