# v1.3.0 Agent Host Phase 3 Review

## Implementation Summary

The MCP server now supports Dirty Excel Region extraction, Change Atom parsing, and impact analysis
as host prepare/submit round trips. A connected host either uses MCP sampling or its Agent Skill to
produce structured output. SpecImpact validates the schema, Evidence IDs, candidate graph,
relation path, changed property, and before value before writing a proposal, report, or decision.

CLI/provider analysis and host analysis now share the report persistence service. Host mode is the
standard route and does not require a SpecImpact provider configuration.

## Changed Files Summary

- `specimpact/application/host_workflow.py`: prepare, approval, submit, audit, and session flow.
- `specimpact/application/host_sampling.py`: MCP host sampling adapter.
- `specimpact/application/host_router.py`: explicit fallback order.
- `specimpact/impact_management/report_store.py`: shared verified report persistence.
- `specimpact/llm_graph/verifier.py`: reused as the final priority authority.
- `specimpact/mcp_server.py`: four host workflow tools and sampling integration.
- `tests/test_host_{workflow,sampling,router}.py`: Fake Host success and failure coverage.

## Known Limitations

- Agent host capability discovery is currently supplied by plugin environment metadata.
- Region submission currently operates one Region per tool round trip to keep Evidence scopes
  bounded and reviewable.
- The stable Job API remains the long-running operation baseline.
