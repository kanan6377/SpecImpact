# v1.2.0 UX Phase 7 Review

## Implementation summary

Phase 7 turns the existing Obsidian graph exporter, LLM trace metadata, and review replay into a
coherent GUI workspace. Users can preview and enqueue a full Vault export, inspect safe
transmission metadata, see the latest replay summary, and recover from failed jobs using
action-specific guidance.

## Changed files summary

- Added a safe integrations API for Obsidian counts, review sessions, replay summaries, and
  allowlisted LLM audit metadata.
- Added an Obsidian GUI view with Vault path control, graph-note preview, export job, and audit
  table.
- Added recovery guidance to failed jobs.
- Expanded external payload redaction for labeled person/customer/account identifiers and
  sensitive dictionary keys.
- Added GUI service/export and redaction regression tests.
- Updated README, GUI/user manuals, integrations, privacy, and phase status.

## Known limitations

- Obsidian remains an exported review surface; local JSONL remains the source of truth.
- Redaction is defense in depth and does not remove the external-transmission approval requirement.
- Replay exposes bounded metadata, not raw prompts or provider responses.

score, and no mandatory external provider. Confidential Phase 6 invention material remains outside
