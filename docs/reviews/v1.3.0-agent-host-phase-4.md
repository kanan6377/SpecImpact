# v1.3.0 Agent Host Phase 4 Review

## Implementation Summary

The repository now contains a Cursor Marketplace package and SpecImpact Plugin. The package wires
the workspace-scoped MCP server into four Agent workflows and supplies evidence-first Rules,
Commands, a hash-only file-change Hook, and three Canvas reference templates.

The Plugin contains no Python implementation. `specimpact agent doctor` checks PATH, the MCP SDK,
and project initialization before Cursor starts a workflow.

## Changed Files Summary

- `plugins/cursor/.cursor-plugin/marketplace.json`: Marketplace entry.
- `plugins/cursor/specimpact/.cursor-plugin/plugin.json`: Plugin manifest.
- `plugins/cursor/specimpact/{mcp,skills,rules,commands,hooks}`: host package.
- `plugins/cursor/specimpact/skills/review/references/canvases`: three projections.
- `specimpact/application/{agent_doctor,agent_hook}.py`: runtime diagnostics and safe Hook handler.
- `tests/test_cursor_plugin.py`: package snapshots and manifest checks.

## Known Limitations

- Canvas has no stable custom-type registration API; Skills generate a Canvas or Markdown view.
- Plugin installation still requires a separately installed `specimpact[mcp]` runtime.
- Cursor host capabilities are declared conservatively; sampling is not assumed.
