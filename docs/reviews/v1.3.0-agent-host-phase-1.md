# v1.3.0 Agent Host Phase 1 Review

## Implementation Summary

The former Web-specific command/query module is now the UI-independent
`specimpact.application.service` layer. `ApplicationService` is the common facade for CLI, Web,
and the later MCP transport. Existing Web imports are preserved by a compatibility module.

Public host contracts are Pydantic models, and their JSON Schemas can be generated from one source.
The project descriptor now belongs to the Application layer rather than the Web registry.

## Changed Files Summary

- `specimpact/application/contracts.py`: public v1 contracts and JSON Schema generation.
- `specimpact/application/service.py`: shared command/query implementation and facade.
- `specimpact/application/__init__.py`: public Application API.
- `specimpact/webui/services.py`: backward-compatible Web import boundary.
- `specimpact/webui/registry.py`: registry using the shared project contract.
- `tests/test_application.py`: contract round trips, schemas, and query parity.
