# v1.2.0 UX Phase 3 Review

## Implementation summary

Phase 3 completes the core Change Review Workspace navigation contract. The selected design source
now contributes document and graph context to LLM-first analysis. Candidate, source, and evidence
selection are deep-linkable, and an evidence action moves directly to its highlighted source line or
cell. The Inspector exposes verifier fields in addition to reason and relation paths.

## Changed files

- Enriched selected-document analysis context with document ID, title, artifacts, and entities.
- Added `impact`, `source`, and `evidence` URL selection state with reload restoration.
- Added one-action evidence-to-source navigation and focused source styling.
- Added verifier match, rule, distance, and relation-status details.
- Added a backend regression test for selected-document graph context.
- Updated README and Japanese manuals.

## Known limitations

- Review status mutation belongs to the unified queue in Phase 4.
- Analysis approval still uses the existing browser confirmation; a structured in-app preview is a
  later UX refinement.
- Source versions and stale evidence are Phase 5 work.

## Scope check

No final impact decision is automated. The selected source adds inspectable context but does not
silently exclude other graph paths. No patent-sensitive analysis algorithm is disclosed.
