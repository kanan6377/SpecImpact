# v1.2.0 UX Phase 8 Review

## Implementation summary

Phase 8 completes the Evidence Review Workspace quality pass. External transmission confirmation
now uses a native modal dialog, keyboard users can skip navigation and inspect graph elements,
mobile change review starts with candidates instead of an obstructing Inspector, and Cytoscape is
loaded only when the Graph view is opened. Metadata and contrast were aligned with the localhost
application boundary.

## Changed files summary

- Added skip navigation, native external-transmission confirmation, table captions, pressed-state
  semantics, search labels, and a keyboard graph selector.
- Added responsive Inspector behavior and narrow-screen dialog controls.
- Increased tertiary text contrast, removed nonzero letter spacing, and retained reduced-motion
  handling.
- Replaced eager Cytoscape import with a Graph-view dynamic import.
- Added `noindex`, referrer, and theme metadata for the localhost-only application.
- Updated release documentation and bumped the package version to 1.2.0.
- Added `specimpact --version` with a CLI smoke test.

## Known limitations

- Cytoscape canvas itself remains visual; the adjacent select and Inspector provide the keyboard
  and assistive-technology path.
- The responsive sidebar uses icon labels exposed to assistive technology but collapses visible
  text at narrow widths.
- Browser checks cover the packaged local GUI, not every operating-system high-contrast mode.
